# 网易云 NCM 解密器

## 用法

双击 `NCM转换器.exe`。

选择 `.ncm` 文件。

输出文件会在原文件同目录。

## 构建

需要：

- Windows
- Visual Studio 2022 Build Tools
- MSVC x86 工具链
- PowerShell

运行：

```bat
build.cmd
```

## 运行

需要 Windows 7 及以上。

Windows 10 / 11 可以直接运行。
